# Smart-HR-Assistant-RAG-Based
Project Overview  The Smart HR Assistant is a Retrieval-Augmented Generation (RAG) powered AI system designed to automate repetitive HR policy inquiries and provide employees with instant, policy-accurate responses.

// Product Definition: //
--> The Problem:
HR manager spends 20% of their time answering repetitive HR inquiries, reducing time available for strategic HR work. This represents 416 hours per year.
Employees, in turn, experience delays and inefficiencies in getting HR-related responses.


// Target Users //
--> HR Managers:
Responsible for answering repetitive employee inquiries on:
* Benefits
* Compensation
* Leave Policies
* Retirement Plans
* Employee Relations
--> Employees:
Require fast and reliable access to HR policy details.


// The Solution: HR Assistance Chatbot (RAG LLM) //
--> A Retrieval-Augmented Generation
(RAG) LLM-powered chatbot that provides instant, structured, and policy-accurate responses to employee HR inquiries.


// Key Features //
1.Al-Powered Smart Search:
Retrieves the most relevant HR policies based on employee questions

2.Summarized HR Responses:
Al extracts key policy points, reducing long document searches.

3.Reference Document Source:
At the end of each chatbot response, the source information will be displayed

4.Slack & Web Portal Integration:
Employees access chatbot via Slack or
HR web portal.

5.24/7 Availability -
HR chatbot operates round the clock,
reducing HR staff workload.


// LLM Configuration //
Property                   MVP Value                       Rationale
License Type     Open-Source LLM (Fine-tuned Llama 3)      Ensures full data privacy and compliance.
Deployment       Hybrid (On-Prem & Cloud)                  Maintains complete control over sensitive HR data.
Temperature      0.2                                       Ensures factually accurate responses.
Top-K Sampling   50                                        Optimizes relevance, prevents hallucinations.
